# Diseños de Spicetify

`apply-colors.sh` monta el tema `Salchipapa` de Spicetify con el `user.css` de aquí y los colores
del tema elegido (`shell/themes/<tema>/spicetify.ini`, como esquema `base`).

| Carpeta | Origen | Licencia |
|---|---|---|
| `text/` | [spicetify/spicetify-themes](https://github.com/spicetify/spicetify-themes) `text/user.css`, commit `bc6106c`; tema *text* de [darkthemer](https://github.com/darkthemer/) | MIT, (c) 2019 morpheusthewhite |

`text/spotify-1.3.css` es nuestro: repite los recuadros y etiquetas de paneles de text sobre los
nombres que siguen existiendo en Spotify 1.3.8 (sus clases legibles ya no están). Se añade detrás
del `user.css` original.
